## Type

Specified for live typesetting: **Beautifully Delicious Script** (primary) and **Aegean Breeze** (secondary). Logo files in this kit are outlined so they open without those fonts. Production substitutes used to draw the outlines are Great Vibes and Julius Sans One (SIL OFL).
