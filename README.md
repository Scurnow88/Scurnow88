# Tasty Treats World — Brand Package

Professional identity files for **Tasty Treats World**, a Naples, Florida dessert studio (`@TastyTreatsWorld`).

**Download:** [TastyTreatsWorld-Brand-Package.zip](TastyTreatsWorld-Brand-Package.zip)

Open `index.html` in a browser to preview the suite, or unzip the package and start with `TastyTreatsWorld-Brand-Package/00-START-HERE.md`.

## What’s in the kit

- Primary circular badge (light, cream, dark, gold, mono)
- Cupcake icon / avatar / favicon
- Wordmark and horizontal lockup
- Outlined SVG + PNG (512 / 1024 / 2048) + JPG
- Instagram avatars, story, highlight covers, watermark
- Business card (PNG + 3.5×2 in PDF)
- Color palette and contact lockup
- Brand guidelines PDF and Instagram review

## Type

Specified for live typesetting: **Beautifully Delicious Script** (primary) and **Aegean Breeze** (secondary). Logo files in this kit are outlined so they open without those fonts. Production substitutes used to draw the outlines are Great Vibes and Julius Sans One (SIL OFL).

Rebuild from source:

```bash
python3 scripts/build_brand_package.py
```
